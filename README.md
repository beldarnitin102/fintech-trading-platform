📈 Fintech Trading Platform (Zerodha Clone)

A full-stack Fintech Trading Platform inspired by Zerodha.
Built with modern web technologies, featuring a public landing page, trading dashboard, and backend API integration.

🏗️ Project Architecture

This project is structured into three main parts:

fintech-trading-platform/
│
├── backend/      → Node.js + Express API
├── frontend/     → Public landing page (Vite + React)
├── dashboard/    → Trading dashboard (React)

🔧 Installation (Local Setup)

Clone the repository:

git clone https://github.com/beldarnitin102/fintech-trading-platform.git
cd fintech-trading-platform
1️⃣ Backend Setup
cd backend
npm install
npm start

Create .env file:

PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_secret_key
2️⃣ Frontend Setup
cd frontend
npm install
npm run dev
3️⃣ Dashboard Setup
cd dashboard
npm install
npm start
